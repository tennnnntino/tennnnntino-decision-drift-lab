# Contributions — experimental stage

Thank you for the interest. This repository is currently a **private publication candidate**; contributions are not being accepted until the owner chooses a software license and a transparent contribution policy.

Once a public issue tracker is explicitly approved, carefully scoped **synthetic counterexamples** are welcomed through the `Break the Handoff` issue form. Submit the smallest fictional example that demonstrates an independently reproducible discrepancy, a declared expected outcome, a command and an observation. Do not submit real messages, passwords, customer data, copied third-party code, offensive requests involving live services or personal information.

A reported bug is valuable even when it undermines a headline claim. Cases are subject to triage and independent verification, and no contribution implies an author was consulted, hired or endorsed the project. Security vulnerabilities should be reported privately after a reporting channel has been established, **not** via public issues.

The 100 generated controls are NOT a substitute for an independently labelled held-out benchmark. No accuracy or security claims are accepted solely on the basis of matching those controls.
